# SEOPress Reference Audit

## 1. Source Inventory
- Repository: https://github.com/wp-seopress/wp-seopress-public
- Version Scope: SEOPress Free & Pro Analysis

## 2. Architecture & Class Mapping
- **Metadata Management**: On-page meta, title templates, social graph
- **XML/HTML Sitemaps**: Dynamic sitemap generation with custom post types and taxonomies
- **URL Rewriting & Redirects**: 301/302/307 redirects, query param matching
- **Broken Link Checker**: Background scanner for 404/500 external and internal links
- **Google Analytics / Matomo**: Ecommerce tracking, events tracking, local hosting of analytics.js

## 3. Key Feature Scope
1. Universal SEO Metabox (Gutenberg, Elementor, Divi, Classic)
2. White Label capabilities
3. Content Analysis with target keywords
4. Structured Data Types (Article, Product, Event, Job, FAQ, HowTo, Local Business)
5. Breadcrumbs Generator (HTML/JSON-LD)
6. Instant Indexing API (Google & Bing IndexNow)
